# 打印卡图 PDF

在组卡区点击「打印卡图 PDF」，按当前卡组的实际数量导出完整卡面；异画按完整卡号保留。原「卡表 PDF」继续提供包含中文效果的卡表。

- A4 纵向纸张（210 × 297 mm），每张卡固定 63 × 88 mm。
- 从左上角各 7 mm 处开始，卡间横纵间距均为 1 mm，每页 3 × 3 张；60 张卡导出 7 页。
- 7 mm 为排版安全边距；固定网格之后的剩余空白留在右侧和底部（满页时分别为 12 mm、24 mm）。
- 打印对话框选择 A4、「实际大小／100%」，关闭「适合页面」；PDF 同时写入不缩放的打印偏好，但打印机设置仍须核对。
- 使用官网原始卡面图片，清晰度受源图限制。任何图片缺失或加载失败都会中止导出并显示卡号，避免输出含空白卡的文件。

## 实现与维护

`public/print-pdf.js` 使用已有 jsPDF 依赖在浏览器内生成文件，点击导出时才加载打包文件。经现有 `/api/image-proxy` 下载图片，最多并发 3 张，每个完整卡号只下载、嵌入一次，副本复用图片。此功能不写数据库、不上传生成的 PDF。

导出开始即固定卡组快照；生成期间编辑卡组不会改变本次文件。图片代理返回的 1 × 1 失败占位图会被拒绝。

`npm run build` 生成被 Git 忽略的 `public/print-pdf.bundle.js`。定向测试：`node --test tests/print-pdf.test.js`。

排版思路参考 [proxy-card-print](https://github.com/iMasanari/proxy-card-print)，实现复用本项目的数据与图片代理。

## 2026-09-29 验证

- 构建和两项定向测试通过，覆盖分页、实际数量、异画、图片复用及失败中止。
- 浏览器实测下载 60 张、两种卡面的 PDF；导出期间修改卡组仍输出原快照，失败占位图显示错误，390 px 手机视口无横向溢出。
- 测试图片通过现有 Vercel 图片代理取得真实官网卡面，再用于本地浏览器测试；本机直连官网曾出现 TLS 中断。
- 用 PyMuPDF 检查全部页面及图片的物理尺寸与坐标：7 页分别为 9、9、9、9、9、9、6 张，均为 A4、卡面 63 × 88 mm、间距 1 mm。Poppler 渲染首尾页并人工检查通过。
