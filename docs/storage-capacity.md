# 容量评估（2026-09-28）

## 当前实测

目标：Neon 项目 `gentle-paper-09879029`，开发分支 `dev-community-decks`。迁移 `003_profiles.sql` 已应用。只读取线上统计；批量模拟全部在本机内存中的 PGlite/PostgreSQL 执行，没有向 Neon 灌入测试卡组。

| 项目 | 实测 |
| --- | ---: |
| Neon 项目 `synthetic_storage_size` | 32,735,232 bytes，31.22 MiB |
| 当前分支 neondb 的 `pg_database_size` | 8,724,480 bytes，8.32 MiB |
| public 业务表、索引与 TOAST 合计 | 327,680 bytes，320 KiB |
| neon_auth 表、索引与 TOAST 合计 | 393,216 bytes，384 KiB |
| 已存内容快照 / 发布记录 / 基础卡号成员 | 9 / 5 / 89 |
| 真实 Auth 用户 / 会话 | 1 / 1，仅统计数量，不读取身份资料 |
| 三份卡库 JSON 文件 | 共 14,167,208 bytes，13.51 MiB；随 Vercel 部署，不占 Neon 数据表空间 |

以上为不同口径，**不能相加**。项目指标、单个分支单个数据库大小、应用表大小范围不同，统计也可能存在刷新延迟。当前项目接口返回 `branch_logical_size_limit_bytes=536870912`（512 MiB），官方免费档标为每项目 0.5 GB。分支采用写时复制，不应把每条分支完整数据库大小简单累加；实际额度以 Neon 控制台为准。

来源：[Neon 当前套餐](https://neon.com/docs/introduction/plans)、[Neon 分支存储计量说明](https://neon.com/blog/new-usage-based-pricing)。恢复历史保留当前为 21,600 秒（6 小时）。

## 本地批量模拟

采用与项目相同的三份 SQL 迁移，构造 10,000 套不同卡组，每套 60 张、17 个基础编号、一个内容快照；作者分布在 1,000 个 ID。测量 `pg_total_relation_size`，包含表、B-tree 索引、TOAST 及分页开销。分别模拟无说明和 200 个中文字符说明。

| 模拟内容（10,000 套） | 无说明 | 200 字中文说明 |
| --- | ---: | ---: |
| 内容快照及索引 | 7,397,376 B | 7,397,376 B |
| 发布记录及索引 | 3,235,840 B | 9,601,024 B |
| 17 万条基础卡号成员及两个索引 | 35,864,576 B | 35,864,576 B |
| 合计 | 44.34 MiB | 50.41 MiB |
| 平均每套 | 4.54 KiB | 5.16 KiB |

按上述模型线性估算（不是容量承诺）：

| 卡组数 | 内容、发布、成员及索引 |
| --- | ---: |
| 1,000 套 | 约 4.4～5.0 MiB |
| 10,000 套 | 约 44～50 MiB |
| 50,000 套 | 约 222～252 MiB |

独立模拟 10,000 个昵称资料，每个为 23 个字符（18 个汉字＋5 位编号），用户 ID 为 32 字符：含主键索引共 2,162,688 bytes（2.06 MiB），平均约 216 bytes/人。真实 Auth 用户、登录会话和验证码数据另计，不能把这个数字当作完整账户总成本。

## 新功能对容量的影响

- 昵称每用户仅存一条。展示历史卡组时关联资料表，改名不用为每套卡组写一份新昵称，也不生成新内容快照。
- 多卡筛选复用已有 `base_code` 索引；所选卡号通过查询参数传递，不保存推荐结果，不新增持久化成员数据。
- 在本模型中，主要占用来自卡号成员及索引。17 种是模拟假设；实际卡组种类越多，此部分越大。
- 编辑或匿名保存会保留新的不可变快照；删除发布记录不会自动删除快照。大规模历史修订、匿名分享、最长 2000 字说明、表膨胀、账户/会话增长、其他分支差异和恢复历史均未包含在上表。

结论：当前新增昵称和多卡推荐本身占用很小，现有免费空间适合初期社区。在“17 种卡＋短说明＋少量历史版本”假设下，数万套卡组有较充足余量；不能仅按 512 MiB 除以单套平均值承诺最大套数。可将项目使用率约 70% 作为再次评估的节点，届时根据真实版本数、卡组种类数和 Auth 占用决定保留策略或升级。
