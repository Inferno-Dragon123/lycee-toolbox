# 多选卡牌检索（待人工审核）

本次在 `codex/search-filters` 预览分支实现，基于正式分支的卡库与已有检索。用户要求先审核预览，通过后再合并 `master`，本次不修改正式分支或数据库配置。

## 交互与匹配规则

- 属性、卡牌种类、稀有度、版本、作品简称、EX 改为多选下拉。点击选中，再次点击取消；长列表支持输入查找。
- 卡号支持直接输入数字或完整编号，例如 `6826`、`LO-6826`；可输入编号前缀和异画后缀 `6826-A`，全角数字也可识别。该简写仅用于检索，不改变卡库或卡组保存时的完整编号。
- 同一字段内各选项按任一匹配，不同字段按同时匹配。属性选择雪和月代表包含雪或月；旧接口单个 `attribute=雪月` 仍代表同时包含雪月。
- 费用、AP、DP、SP、DMG 每项合并为一个上下限控件，允许只填写一端；0 是有效值，下限大于上限返回错误。
- 已选条件栏列出文字、范围、多选和基本能力，可单独移除，也可使用「清空条件」。条件改变后显示「待应用」，点击搜索后应用；翻页继续使用已经应用的条件。
- 基本能力菜单左侧选择能力，鼠标悬浮或点击后右侧显示对应代价／效果。右侧「任意代价／效果」匹配该能力的所有形式；选择具体形式会取消该能力的任意匹配，反之亦然。手机支持点击，Esc 关闭菜单。
- 分页支持「最后一页」及输入整数页码后点击跳转／按 Enter。空结果和加载期间禁用分页，越界页码提示修正；跳页继续使用已应用条件，搜索失败后保留原结果和分页。

## 基本能力来源与识别

按用户提供的 `D:/Code/.vscode/lycee-toolbox/基本能力.md` 及后续补充的「コンバート → 换装」收录 19 种能力，术语固定在 `lib/basic-abilities.js`。只读取日文效果描述开头连续的已知能力方括号，支持嵌套代价符号、半角片假名、全角数字及分隔符。遇到正文标签或其他文字即停止，正文中获得／引用某能力不参与本项筛选。换装二级选项保留费用及原文目标角色名；「サポート → 支援」作为效果术语，不与「サポーター → 支援者」混淆。

能力参数使用日文原文生成稳定编号；中文仅用于显示。前导能力顺序一致时显示已有中文代价／效果，同时保留对应日文供核对；暂无可匹配中文时显示日文。

能力参数只去除包住整个参数的外层方括号，费用保留 `[0]`、`[花花]` 等惯用显示，内部符号和效果内容不变。充能 `[3]`／`3`、离场惩罚的抽一张及结合的护盾＋1已各合并为一项，索引同时覆盖所有原形式；「抽一张」与「可以抽一张」仍分别筛选。

相同日文参数统一采用 `translatedAt` 最新的匹配中文。`node scripts/backfill-translation-dates.js` 从完整 Git 历史补记每张卡译文最后实际变化的提交时间（历史时间为提交时间近似值），不修改译文或调用翻译 API；初次导入的旧译文无时间时按最早处理。日常翻译脚本记录新译文时间，缓存／复用其他卡面的译文保留原时间，避免将旧译文复制误判成新翻译。同批译文时间相同则沿用卡号排序中的首个匹配译文。

`GET /api/cards?facets=1` 追加 `abilityFacets`；现有 `facets` 保持原结构。多选使用重复参数，例如 `category=キャラクター&category=イベント`、`ability=charge:1&ability=charge:2`。能力家族可使用 `ability=charge`。未知筛选值返回 400。

菜单数据与能力索引由正式 JSON 在运行时构建，无数据库迁移，也不调用翻译 API。
